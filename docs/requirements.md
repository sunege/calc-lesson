# けいさん れんしゅう アプリ 要件定義書

- 版: 0.5(実装にあわせて技術構成と細部を更新)
- 作成日: 2026-10-08
- 対象: 小学1・2年生
- 想定端末: タブレット(iPad / Chromebook / Android タブレット / Windows タブレット)

---

## 1. 目的・コンセプト

| 項目 | 内容 |
| --- | --- |
| 目的 | 1・2年生で習う計算(たし算・ひき算・九九)を、くり返し練習して速く正確に解けるようにする |
| コンセプト | 「やればやるほど はやくなる!」を自分の目で確かめられる計算アプリ |
| 動機づけ | 正解・不正解のたびに派手なエフェクトを出す。結果画面で過去のタイムとの比較をグラフで見せる |
| 利用シーン | 家庭学習・学校の朝学習など。1回あたり 1〜5分程度 |

### 1.1 前提・制約

- サーバーは使わない。ブラウザだけで完結する静的 Web アプリにする
- データ保存は **ブラウザの localStorage のみ**。端末をまたいだ同期はしない
- ログインや個人情報の入力はしない
- 技術スタック: **Vite + React + TypeScript**

## 3. 出題モード(機能要件の中心)

### 3.1 モード一覧

| モードID | 表示名 | サブ表示 | 出題範囲 | 問題数 | 出題順 |
| --- | --- | --- | --- | --- | --- |
| `add1` | たしざん ① | くりあがり なし | a + b(1 ≤ a、0 ≤ b、a + b ≤ 10。0 + x は除く) | **55問** | 全問をランダム |
| `sub1` | ひきざん ① | くりさがり なし | a − b(1 ≤ b ≤ a ≤ 10。0 を引く式は除く) | **55問** | 全問をランダム |
| `add2` | たしざん ② | くりあがり あり | a + b(1 ≤ a, b ≤ 9、a + b ≥ 11) | **36問** | 全問をランダム |
| `sub2` | ひきざん ② | くりさがり あり | a − b(11 ≤ a ≤ 18、2 ≤ b ≤ 9、a の一の位 < b) | **36問** | 全問をランダム |
| `kuku-{n}-seq` | {n}のだん | じゅんばん | n × 1 〜 n × 9(n = 2〜9) | 9問 | n×1 → n×9 の順 |
| `kuku-{n}-rand` | {n}のだん | ばらばら | n × 1 〜 n × 9(n = 2〜9) | 9問 | ランダム |
| `kuku-master` | くく ますたー | ぜんぶの だん | 2の段〜9の段の72問(2×1〜9×9)から抜き出す | **20問** | 72問から重複なしでランダムに20問 |

### 3.2 出題範囲の詳細

#### たしざん ①(`add1`)
- たされる数 a = 1〜10、たす数 b = 0〜(10 − a)。和は 1〜10
- **0 + x の形(0 + 0、0 + 7、0 + 10 など)は出さない**
- x + 0 の形(7 + 0、10 + 0 など)は出す
- **2 + 3 と 3 + 2 は別の問題として出す**
- a = 1 のとき 10通り、a = 2 のとき 9通り … a = 10 のとき 1通り → **55問**

#### ひきざん ①(`sub1`)
- ひかれる数 a = 1〜10、ひく数 b = 1〜a
- **答えが負の数になる問題(3 − 5 など、ひく数のほうが大きいもの)は出さない**
- **0 を引く問題(5 − 0、10 − 0、0 − 0 など)は出さない**
- 答えが 0 になる問題(5 − 5、10 − 10 など)は出す
- 1 − 1 から 10 − 10 まで → 1 + 2 + … + 10 = **55問**(答えは 0〜9)

#### たしざん ②(`add2`)
- 一桁(1〜9)どうしで和が 11 以上
- たしざん ① と同じく、**2 + 9 と 9 + 2 は別の問題として出す**
- 和 11:8通り、12:7通り … 18:1通り = **36問**
- 和がちょうど 10 になるもの(1 + 9 など)はたしざん ① に入っているため、ここには含めない

#### ひきざん ②(`sub2`)
- ひかれる数 11〜18、ひく数 2〜9 で、**一の位から引けない(くりさがりが起きる)もの**だけ
- 条件: `a % 10 < b`(このとき答えは必ず 2〜9 の一桁)
- ひかれる数 11:8通り、12:7通り … 18:1通り = **36問**

#### 九九 各段(`kuku-{n}-*`)
- 2の段〜9の段から段を1つ選び、さらに出題順を選ぶ
  - **じゅんばん**: n × 1, n × 2, … n × 9
  - **ばらばら**: 9問をシャッフル
- 1の段は対象外

#### 九九マスター(`kuku-master`)
- 2の段〜9の段の 72問をシャッフルし、先頭の **20問** を出す(1回のプレイの中では重複しない)
- かけ算は九九の唱え方が違うため、2 × 3 と 3 × 2 は別の問題として扱う

### 3.3 出題ロジック共通仕様

- 各モードの問題集合を全部作り、**Fisher–Yates シャッフル**で並べ替えて出す(九九マスターは並べ替えた先頭20問)
- 1回のプレイで同じ問題は出さない(入れかえた式は別の問題とみなす)
- 問題生成は副作用のない純粋関数として実装する。乱数は引数で差し替えられるようにし、テストできるようにする

```ts
type Operator = '+' | '-' | '×';
interface Problem { a: number; b: number; op: Operator; answer: number; }
type ModeId =
  | 'add1' | 'sub1' | 'add2' | 'sub2'
  | `kuku-${2|3|4|5|6|7|8|9}-${'seq' | 'rand'}`
  | 'kuku-master';
```

## 4. 画面要件

### 4.1 画面遷移

```
[タイトル/モードせんたく] ──┬──▶ [カウントダウン 3・2・1] ─▶ [もんだい] ─▶ [けっか(リザルト)]
        ▲                 │                                  │ やめる       │
        │                 └─▶ [くくの だん せんたく] ──────────▶┘              │
        │                                                                     │
        └────────────────── もういちど / もどる ◀──────────────────────────────┘
[せってい](タイトルの はしの ⚙ から。音のオン/オフ、きろくの けしかた)
```

画面の切り替えは React の state で管理する。ルーターは使わない(URL の共有が必要ないため)。

### 4.2 タイトル/モード選択画面

- アプリ名(例: 「けいさん ちゃれんじ」)とキャラクターを表示する
- モードを大きなカードボタンで並べる
  - たしざん ① / ひきざん ① / たしざん ② / ひきざん ② / くくの だん / くく ますたー
- 各カードに **じこベスト(最速タイム)** と **あそんだ かいすう** を小さく出す
- 1年生向け(たし算・ひき算)と2年生向け(九九)で、カードの色やグループを分ける

### 4.3 九九の段選択画面

- 2〜9 の段ボタン(8個)と、「じゅんばん」「ばらばら」の切り替えを置く
- 段ボタンごとに、選んでいる出題順のじこベストを表示する
- 段ボタンを押すと、すぐにカウントダウンが始まる(操作の手順を減らすため)

### 4.4 カウントダウン画面

- 「3 → 2 → 1 → スタート!」を大きくアニメーションで見せる(約3秒)
- **iOS で音を鳴らせるようにするため、この画面に入る直前のタップで AudioContext を有効にする**

### 4.5 問題画面

#### レイアウト(横向き)

```
┌────────────────────────────────────────────────────────────┐
│ [やめる]     たしざん ①      ⏱ 0:42      12 / 55 もん        │
│ ▓▓▓▓▓▓▓▓░░░░░░░░░░░░░░░░░░░░░░░░ (しんちょく ばー + きゃら)  │
├───────────────────────────────┬────────────────────────────┤
│                               │   ┌───┐ ┌───┐ ┌───┐        │
│                               │   │ 7 │ │ 8 │ │ 9 │        │
│       7 + 5 = [ 1 2 ]         │   ├───┤ ├───┤ ├───┤        │
│                               │   │ 4 │ │ 5 │ │ 6 │        │
│     (もんだいを おおきく)      │   ├───┤ ├───┤ ├───┤        │
│                               │   │ 1 │ │ 2 │ │ 3 │        │
│     🔥 5れんぞく せいかい!     │   ├───┤ ├───┤ ├───┤        │
│                               │   │けす│ │ 0 │ │こたえる│   │
│                               │   └───┘ └───┘ └───┘        │
└───────────────────────────────┴────────────────────────────┘
```

- **縦向き** のときは、上に問題、下にテンキーを置く
- 問題の数字は画面の高さの 15% 以上の大きさにする(目安は 96px 以上)
- 答えの入力欄は問題式の □ の位置にそのまま表示する
- 経過タイムを分:秒で表示する(子どもが「はやく!」と意識できるように)
- 進み具合は「12 / 55 もん」とバーで表示し、バーの上をキャラクターが歩いて進む演出をつける
- 「やめる」は確認ダイアログ(「やめても いい?」はい/いいえ)を出す。途中でやめたときは記録しない

#### テンキー入力

| ボタン | 動作 |
| --- | --- |
| 0〜9 | 末尾に数字を追加する。**最大2桁**(答えの最大値は 81)。先頭の 0 は「0」単体のときだけ許す |
| けす | 1文字消す(長押しで全部消す) |
| こたえる | 判定する。入力が空のときは押せない(グレー表示) |

- 電卓と同じ並び(7 8 9 / 4 5 6 / 1 2 3 / けす 0 こたえる)にする
- ボタンは **一辺 72px 以上**、ボタンどうしのすき間は 12px 以上
- `pointerdown` で反応させ、押したことがすぐ見えるようにする(押し込みアニメと「ポッ」という小さな音)
- 物理キーボード(数字・Backspace・Enter)にも対応する(PC 用のおまけ機能)

#### 判定と進行

- **正解するまで次の問題に進まない**
- **得意な子がテンポよく進めるように、エフェクトで子どもを待たせない**
- 正解のとき: 答えの欄が光り、**約0.3秒** で次の問題に切り替わる。紙ふぶきなどの派手な演出は、次の問題が出たあとも画面の後ろで続ける
- 不正解のとき: 問題カードが揺れ(約0.3秒)、入力欄が空になる。すぐに同じ問題に答え直せる
- テンキーを止めるのは、上の約0.3秒の切り替えの間だけにする(連打による誤入力を防ぐため)
- 最後の問題に正解したらクリア演出を出し、結果画面へ進む

```
│   たいむ  1ぷん 23びょう    まちがい 2かい   ★★☆           │
│   👑 じこベスト こうしん!  まえより 5びょう はやく なったよ!│
│                                                            │
│   ┌ きみの きろく(ぼうが みじかいほど はやい!)─────────┐  │

│   │  90┤ ▇  ▇  ▇                                        │  │
│   │  60┤ ▇  ▇  ▇  ▇  ▇  👑                              │  │
│   │    └─1──2──3──4──5──6(きょう)── かいめ               │  │

│        [ もういちど ]          [ ほかの もんだい ]          │
└────────────────────────────────────────────────────────────┘
```

#### 表示する内容
- クリアタイム(「1ぷん 23びょう」の形。1分未満は「45びょう」)
- まちがいの回数
- ほし評価(まちがい 0回 → ★★★「はなまる!」、1〜3回 → ★★☆、4回以上 → ★☆☆)
- 比較メッセージ(ほめる言い方だけにする)
  - 初回: 「はじめての きろくだよ! つぎは もっと はやく なるかな?」
  - じこベスト更新: 「👑 じこベスト こうしん!」(特別演出つき)
  - 前回より速い: 「まえより ○びょう はやく なったよ!」
  - 前回より遅い: 「おしい! つぎは もっと はやく なるよ!」

#### タイムの推移グラフ
- **棒グラフ** にする(2年生の算数で学ぶ形式で、子どもにも読みやすい)
- 横軸は「○かいめ」、縦軸はタイム(びょう)
- 表示するのは **直近10回**。今回の棒は色を変え、下から伸びるアニメーションで出す
- 最速の回の棒の上に 👑 を置く。じこベストの高さに点線を引く
- グラフの見出しに「ぼうが みじかいほど はやい!」と書く(速くなったことが直感で分かるように)
- 記録が2回以上あるときは、初回と今回の差を「さいしょより ○びょう はやく なったよ!」と出す
- 外部ライブラリは使わず、**SVG で自作**する(演出の自由度とバンドルサイズのため)

#### ボタン
- 「もういちど」: 同じモードですぐ再開する
- 「ほかの もんだい」: モード選択に戻る

### 4.7 設定画面

- 音のオン/オフ(初期値はオン)
- 記録を消す: モードごと、または全部。**3秒長押し+確認ダイアログ** にして、子どもが誤って消さないようにする
- 保護者向けの説明文だけは漢字を使ってよい

## 5. エフェクト・演出要件

### 5.0 基本方針: 派手だけど待たせない

- 子どもの操作を止めるのは、正解・不正解とも **約0.3秒だけ**
- 派手な演出(紙ふぶき・文字・キャラクター)は **入力を邪魔しない重ね表示** にする
  - `pointer-events: none` の層に描き、テンキーの操作を受け止めない
  - 問題の式とテンキーの上には大きく重ねない。文字は問題カードの上の空きなどに出す
- 前の演出が終わる前に次の正解をしても、新しい演出が重なって出るようにする(速く解くほど、画面がにぎやかになる)

### 5.1 正解エフェクト(入力の停止は約0.3秒。演出は後ろで約1秒続く)
- 画面の両はしから **紙ふぶき**(`canvas-confetti`)
- 「せいかい!」の文字が跳ねて現れ、すぐ消える。「すごい!」「やったね!」「ばっちり!」などをランダムに出す
- 答えの欄が緑に光り、星がはじけるパーティクルを出す
- 明るい上昇音(ピロリン♪)
- **れんぞく正解の演出**: 3・5・10連続などの節目で「🔥 5れんぞく!」を出し、紙ふぶきの量と色を増やす

### 5.2 不正解エフェクト(入力の停止は約0.3秒)
- 問題カードを左右に揺らす(シェイク)
- 「✕」と「おしい! もういちど!」を出す。キャラクターは困り顔だが、責めない表現にする
- 低めのブブー音(不快にならない程度の音量と長さ)
- 入力欄を空にする。連続正解のカウントは 0 に戻す

### 5.3 クリア演出(約2〜3秒)
- 花火(紙ふぶきを左右から連続で出す)と「くりあ!」の文字
- じこベストを更新したら、王冠 👑 が上から降ってくる演出とファンファーレを追加する

### 5.4 共通
- 効果音は **Web Audio API でコードから合成する**(音声ファイル不要、オフラインでも鳴る)
- OS の「視差効果を減らす」(`prefers-reduced-motion`)がオンのときは、揺れ・大量の紙ふぶきを控えめにする
- エフェクトは CSS アニメーションと canvas-confetti で作り、60fps を目安にする

## 6. 記録(localStorage)要件

### 6.1 記録の定義

- **クリアタイム** = 1問目が表示された瞬間から、最終問題に正解した瞬間までの時間
- エフェクトでテンキーを止めている時間(正解・不正解のあとの約0.3秒)は **タイムに含めない**(解く速さだけを測るため)
- 不正解のあとの解き直し時間はタイムに含める(まちがえると遅くなる)
- 測定には `performance.now()` を使う
- アプリがバックグラウンドに回ったら(`visibilitychange`)タイマーを止め、戻ったら再開する
- 途中でやめたプレイは記録しない

### 6.2 データ構造

```ts
// localStorage key: "calc-lesson:v1"
interface StoredData {
  version: 1;
  settings: { sound: boolean };
  records: Partial<Record<ModeId, PlayRecord[]>>;
}

interface PlayRecord {
  timeMs: number;      // クリアタイム(ミリ秒)
  mistakes: number;    // まちがいの回数
  playedAt: string;    // ISO 8601 日時
}
```

- モードごとに古い順で保存する。上限は **100件**。超えたら古いものから消す
- 九九の各段は「じゅんばん」と「ばらばら」を **別の記録** として扱う(難しさが違うため)
- `version` を持たせ、将来データの形を変えるときに移行できるようにする
- localStorage が使えない環境(プライベートブラウズなど)でも、アプリは動くようにする(記録しないだけ。設定画面に注意文を出す)
- 読み込んだデータが壊れていたら初期化する(型チェックをする)

## 7. デザイン要件

### 7.1 文字・言葉づかい
- 子ども向けの文言は **すべてひらがな** にし、**分かち書き**(「たしざん を はじめる」のように文節で区切る)にする
- 外来語はカタカナにする(「スタート」「タイム」「クリア」「じこベスト」「マスター」)。それ以外はひらがなにする
- 数字はアラビア数字で、大きく太く表示する
- 演算子は「+」「−」「×」「=」を大きく、色分けする(+ は赤系、− は青系、× は緑系など)

### 7.2 フォント
- 丸ゴシック系の Web フォント(候補: **Zen Maru Gothic** / M PLUS Rounded 1c)
- オフラインでも使えるよう、フォントファイルはアプリに同梱する(`@fontsource` を使う)

### 7.3 色・雰囲気
- 明るいパステル調の背景に、はっきりした原色のアクセントを合わせる
- モードごとにテーマカラーを決める(たしざん:オレンジ、ひきざん:水色、九九:みどり、マスター:むらさき/金)
- 正解は緑、不正解は赤系。ただし赤は強くしすぎない
- 文字と背景のコントラスト比は 4.5:1 以上にする
- マスコットキャラクター(動物など)を1体置き、待機・喜ぶ・困るの3つの表情を出す(SVG か絵文字で作る)

### 7.4 タブレット対応
- 主な対象は 10インチ前後のタブレット(768×1024 〜 1366×1024 の CSS px)。横向き・縦向きのどちらにも対応する
- スマホ幅(375px)でも崩れずに遊べるようにする(最低限の対応)
- タッチ操作の調整:
  - `touch-action: manipulation`(ダブルタップで拡大しない)
  - `user-select: none`(長押しで文字選択しない)
  - `overscroll-behavior: none`(引っ張って再読み込みしない)
  - タップしたときの青いハイライトを消す(`-webkit-tap-highlight-color: transparent`)
- `viewport` を固定し、ピンチで拡大しないようにする

## 12. 決定事項

| # | 論点 | 決定 |
| --- | --- | --- |
| Q1 | 0 を使う問題 | たし算は **0 + x の形をすべて除く**(0 + 0、0 + 7 など)。x + 0 の形(7 + 0 など)は出す。ひき算は **0 を引く式をすべて除く**(5 − 0、10 − 0、0 − 0)。答えが 0 になる式(5 − 5)は出す |
| Q2 | たし算で入れかえた式(2 + 3 と 3 + 2) | **別の問題として出す**。たしざん ① は 55問、たしざん ② は 36問 |
| Q3 | 九九マスターの問題数 | **2〜9の段の72問からランダムに20問** |
| Q4 | 1の段を入れるか | 入れない(2〜9の段) |
| Q5 | エフェクトの時間をタイムに入れるか | **入れない**。エフェクトはなるべく短くし、入力を止めるのは約0.3秒だけ。派手な演出は後ろで続ける |
| Q6 | グラフの形 | 直近10回の棒グラフ(短いほど速い) |
| Q7 | 複数の子どもが同じ端末を使う場合 | **1人用**(利用者を切り替える機能は作らない) |
